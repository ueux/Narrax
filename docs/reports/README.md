# Reports

Generated artifacts, committed so that changes to the pipeline are visible in review as a diff
rather than as a claim.

| Report | Generated by | What it shows |
|---|---|---|
| [sample-dataset-report.md](sample-dataset-report.md) | `python -m app.cli.inspect_dataset` | Volume, provenance, language mix, content length, missing values, duplication, exclusions and coverage for the committed recorded corpus |

## How the sample report is produced

It is produced by the real pipeline, from committed fixtures, with no network access:

```bash
cd backend
alembic upgrade head
python -m app.cli.ingest_recorded \
  --input-dir tests/fixtures/reddit \
  --topic "AI regulation" \
  --communities technology programming \
  --limit 50
python -m app.cli.inspect_dataset --top-communities 10 \
  --output ../docs/reports/sample-dataset-report.md
```

**This is not live Reddit data.** Live collection requires OAuth application credentials, which this
project does not hold; the corpus is a synthetic, Reddit-shaped dataset committed at
`backend/tests/fixtures/reddit/`. It is deliberately adversarial — deleted and removed posts and
comments, an empty body, a body field missing entirely, a URL-only comment, an emoji wall, repeated
slang, contentless filler, non-English text, three levels of nesting, a duplicate posted twice,
duplicates across two posts, and a comment whose parent was never collected — so that between them
the fixtures exercise every value in the exclusion vocabulary.

Re-running the ingest before regenerating the report is safe and expected: collection is idempotent,
so the second run reports `0 new, 26 refreshed` and rewrites no authored text. Only the `Generated:`
timestamp should change between runs.
