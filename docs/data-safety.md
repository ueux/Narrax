# Data Safety

NarraX uses public data for aggregate intelligence only. It must not become a tool for
tracking or profiling individuals.

## We do NOT build

- Deanonymization
- Personal dossiers
- Private-user surveillance
- Cross-platform identity stitching
- Sensitive personal attribute inference
- Individual political profiling
- Hidden user tracking

## Guidelines

1. Keep authors pseudonymous wherever practical.
2. Do not represent Reddit (or any single platform) as equivalent to the whole
   population. Results are scoped to the analyzed public discussions.
3. Prefer aggregate, population-level intelligence over individual-level claims.
4. Use careful language such as "Among the analyzed public Reddit discussions..."
   rather than "Everyone believes...".
5. Review any new feature against this document before implementation.
